# Risol Homemade Project

Struktur proyek:

- `public/`: Folder konten statis (frontend).
  - `index.html`: Struktur utama halaman web.
  - `style.css`: File gaya (CSS).
  - `script.js`: Logika frontend (React bundle).
- `server.ts`: Backend Express untuk API Midtrans.
- `.env`: Konfigurasi variabel lingkungan (simpan kunci rahasia di sini).
- `package.json`: Definisi proyek dan dependensi.
- `bun.lockb`: Lockfile dependensi (jangan edit).
- `tsconfig.json`: Konfigurasi TypeScript.
